# Busya Contacts 📒

**Легкая автономная записная книжка от бренда Busya™.**

## О приложении
Официальное приложение **BusyaContacts**. Утилита работает полностью автономно, сохраняя вашу информацию в локальном формате JSON. 

Приложение спроектировано с упором на максимальную безопасность и приватность: оно **не запрашивает** доступ к файловой системе устройства или вашим системным контактам. Используется только базовое сетевое разрешение, которое необходимо для корректного открытия внутренних ссылок.

## Особенности
* 🗂 **JSON-архитектура:** Все данные хранятся в простом, прозрачном и легко переносимом текстовом формате.
* 🔒 **Полная приватность:** Никакого скрытого сбора данных и избыточных разрешений.
* ⚡ **Автономность:** Стабильная работа без привязки к облачным сервисам.
