# Busya-Contacts
Busya Contacts App
Busya Contacts — Ваша безопасная записная книжка

Представляем легкое, быстрое и полностью безопасное веб-приложение для управления контактами. Оно создано для тех, кто ценит приватность, минимализм и полный контроль над своей информацией. Никаких облачных баз данных, скрытых синхронизаций или телеметрии — все ваши данные остаются строго на вашем устройстве.

Ключевые особенности:

    Абсолютная приватность (Offline-First): Все контакты, адреса, заметки и даже сжатые фотографии сохраняются исключительно в локальной памяти вашего браузера или телефона.

    Многоязычность без границ: Приложение говорит на вашем языке! Интерфейс поддерживает мультиязычность и автоматически адаптируется под вас, делая использование комфортным в любой точке мира.

    Современный интерфейс: Чистый, интуитивно понятный дизайн со скругленными карточками, плавной навигацией и поддержкой Светлой/Тёмной темы.

    Гибкая настройка профилей: Добавляйте любые номера телефонов, почтовые ящики и социальные сети. Удобная функция «Свой сервис» позволяет создать абсолютно любую пользовательскую категорию.

    Удобный импорт и экспорт: Создавайте резервные копии вашей телефонной книги в формате JSON в один клик и легко переносите их между устройствами.

    Интеграция со смартфонами: На поддерживаемых мобильных устройствах доступен быстрый импорт системных контактов напрямую в приложение.

Прозрачность и законность:
Приложение разработано в строгом соответствии с законодательством РФ, не собирает персональные данные и открыто информирует о статусе сторонних платформ. Данное приложение не охраняется авторским правом или лицензией — пользуйтесь им свободно.
